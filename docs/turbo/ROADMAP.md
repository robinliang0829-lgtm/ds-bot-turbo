# ds-bot-turbo 移植路线图

这是在 DS-Bot 上逐步移植 OpenMausBot 能力的项目。首批交付包含可执行的能力，不代表整个 OpenMausBot 已移植。源码基线、许可与依赖见 [RESEARCH](RESEARCH.md)。

## 本分支提供

- **Magpie**：连接向导、Responses/Chat Completions 协议、只读模型发现和手工模型输入；每个连接创建独立路由及凭据引用，Bot 用现有模型选择器分别选择。
- **稳定模型连接**：用户可固定一个 Bot 的连接。连接失效、群 Session 未能应用或复制时不静默换到另一连接。继续使用 DSH 宿主路由和辅助请求策略。
- **OpenMausBot 工具选择核心**：实际移植 allow/deny 解析、匹配与扩大检查；集成用户设置、系统提示和 DSH 工具执行 guard。覆盖独聊、群成员、分段和 PTC 嵌套调用。
- **兼容限制**：工具描述可能仍可见；本开关不控制允许工具内部的文件/网络行为，也不能覆盖 CLI 原生工具。CLI 组合和尚未结束的 CLI stream 会阻止保存限制。
- **后续配置基础**：严格 runtime profile 解析器及合成示例，当前没有成为生产执行入口，不宣称私有账号 ACL 已落地。

阅读 [设计](../plans/2026-11-06-turbo-runtime-profiles.md) 与 [隔离验证](SMOKE.md)。当前 npm 包名保留 `ds-bot` 以兼容 DSH 插件注册；这不是已经发布的 `ds-bot-turbo` npm 包。仓库源码不自动替换用户安装。

## 后续里程碑与验收

### 接口实例与私有技能

从 OpenMausBot 的 private/library/imported/native 来源模型开始，逐项接入 DS-Bot capability 生命周期。连接器需要稳定账号实例、明确共享名单、撤销时拒绝新调用。必须用两个 Bot、不同合成账号的端到端测试证明不会串用；设计评审前不把 capability 勾选解释成强隔离。

技能内容更新、来源证明、审核失效与工具依赖要成为一个可检查的状态。保留原有技能、记忆和群聊迁移兼容。

### 同一应用内的 Bot 工作台

将 OpenMausBot 的 Bot 列表、对话、模型/技能/接口分区按独立组件迁移到 DSH 插件，用现有主题 token 和公开 slots。传统模式与 BOT 模式在同一壳内切换；打开另一个 Electron 窗口不能算完成。

验收包含切换保留会话、每 Bot 显示实际连接/能力、空态、离线态、错误重试、键盘访问、窄窗口及中英文。不要导入全局 Tailwind、企业模块或受限资产。

### 线程、任务与运行可观测性

研究 OpenMausBot 的线程覆盖与 Bot 默认、任务调度/运行记录、委派进度显示，映射 DS-Bot 现有 Session、日程和群回合。每项先列上游已有能力与新增差异，再移植必要模块，避免并存两套任务数据库。

### 分发与迁移

独立 Turbo 版本与发布产物、可回退的安装/迁移、数据备份和恢复。先在隔离 DSH_HOME 验证，再对用户安装执行明确的部署动作；不可从测试脚本写入现有用户数据。公开发布时保留 DS-Bot 与 OpenMausBot 许可、提交来源及修改记录。
